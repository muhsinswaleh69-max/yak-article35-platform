# yak-article35-platform
Article 35 platform for Youth Alive! Kenya. Governance repository, public participation hub, memo generator (DOCX/PDF), AI-assisted summarization (draft-pending-review), response tracker &amp; budget calendar. Next.js + Laravel. DPA 2019 compliant, mobile-first, low-bandwidth optimized. Phase 1: Nairobi, Kajiado, Machakos
